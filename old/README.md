# Archived scripts

The files in this directory are historical source material retained to document
the development of DICE and to support method comparisons with earlier work.
They are not part of the supported DICE interface.

Do not run these scripts on current or irreplaceable data. Several were written
for older Python/CASA environments and contain broad `rm -rf` cleanup commands,
hard-coded filenames, and assumptions about an obsolete directory layout. Use
the documented workflows under `scripts/`, `tutorials/`, and `docs/` instead.

`README_2018.md` is the original project note and is preserved as historical
documentation.
