# GHOST / ALMA2040 workflows

These scripts reproduce the public GHOST and ALMA2040 analysis without
distributing measurement sets. Downloaded GHOST products and locally
generated CASA tables remain below `data/` and are ignored by Git. The
ordered workflow is machine-readable in
`configs/ghost/workflow_manifest.json`.

The recommended scientific comparison uses each configuration at its native
resolution, four pixels per minor beam, the full PB region down to PB=0.2,
natural weighting, dirty images, and no taper. The earlier common-resolution
taper branch (`examples/31`--`37`) is retained only as research history and
must not be presented as the fiducial configuration comparison.

The first migrated workflow is the native-resolution, full-primary-beam
summary plot:

```bash
PYTHONPATH=src python scripts/ghost/plot_native_full_pb_metrics.py \
  --config configs/ghost/native_full_pb.json
```

It reads the per-configuration CSV products generated by the CASA
injection/recovery run and writes PNG, PDF, CSV, and provenance JSON files.
The public scripts are grouped conceptually into preparation/inspection, F1
design validation, native F1--F6 production, and robustness diagnostics.
Diagnostic scripts cover realization convergence, thresholds, MS
weights/flags, controlled bright-neighbour sidelobes, non-Gaussian visibility
noise, and extension smoke tests.

Migration validation currently establishes:

- exact F1 one-realization native source, threshold, and summary tables;
- exact F1--F6 native metric CSV (132 rows);
- byte-identical matrix baseline CSV;
- byte-identical independent-F1, convergence, threshold, sidelobe,
  non-Gaussian, and extension diagnostic tables.

The corresponding numbered files in `examples/` remain as reference
implementations until the final legacy cleanup.
