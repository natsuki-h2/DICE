# Changelog

All notable public changes to DICE will be documented here.

## 0.1.0 - 2026-10-20

- Add visibility-domain point-source injection with CASA.
- Add CASA-independent image- and cube-domain injection.
- Add configurable positive and negative source extraction.
- Add completeness, contamination, flux-recovery, and astrometric metrics.
- Add continuum and fixed-width line-injection tutorials.
- Add English and Japanese student quick-start guides.
- Add population-forward examples for source counts and luminosity functions.
